# 订单状态流转图

## 状态转换关系

```
                    ┌─────────────┐
                    │   待支付    │ (初始状态)
                    │  Pending    │
                    └──────┬──────┘
                           │
                ┌──────────┼──────────┐
                │          │          │
             pay()      cancel()      │
                │          │          │
                ▼          ▼          │
         ┌──────────┐  ┌─────────┐   │
         │  已支付  │  │ 已取消  │◄──┤
         │   Paid   │  │Cancelled│   │
         └────┬─────┘  └─────────┘   │
              │              ▲        │
              │              │        │
           ship()        refund()     │
              │              │        │
              ▼              │        │
         ┌──────────┐        │        │
         │  配送中  │────────┘        │
         │ Shipping │                 │
         └────┬─────┘                 │
              │                       │
              │                       │
         deliver()                refund()
              │                       │
              ▼                       │
         ┌──────────┐                 │
         │  已完成  │─────────────────┘
         │Completed │
         └────┬─────┘
              │
           review()
              │
              ▼
           (结束)
```

## 状态操作矩阵

| 状态 / 操作 | pay() | ship() | deliver() | cancel() | refund() | review() |
|------------|-------|--------|-----------|----------|----------|----------|
| **待支付** | ✅ → 已支付 | ❌ | ❌ | ✅ → 已取消 | ❌ | ❌ |
| **已支付** | ❌ | ✅ → 配送中 | ❌ | ❌ | ✅ → 已取消 | ❌ |
| **配送中** | ❌ | ❌ | ✅ → 已完成 | ❌ | ✅ → 已取消 | ❌ |
| **已完成** | ❌ | ❌ | ❌ | ❌ | ❌ | ✅ |
| **已取消** | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ |

## 状态说明

### 1. 待支付（PendingPayment）
- **可执行操作**：
  - ✅ `pay()` - 支付订单 → 转到"已支付"
  - ✅ `cancel()` - 取消订单 → 转到"已取消"
- **不可执行操作**：
  - ❌ `ship()` - 还未支付
  - ❌ `deliver()` - 还未支付
  - ❌ `refund()` - 还未支付，无需退款
  - ❌ `review()` - 还未完成

### 2. 已支付（Paid）
- **可执行操作**：
  - ✅ `ship()` - 发货 → 转到"配送中"
  - ✅ `refund()` - 退款 → 转到"已取消"
- **不可执行操作**：
  - ❌ `pay()` - 已经支付，无法重复支付
  - ❌ `deliver()` - 还未发货
  - ❌ `cancel()` - 已支付，需要退款才能取消
  - ❌ `review()` - 还未完成

### 3. 配送中（Shipping）
- **可执行操作**：
  - ✅ `deliver()` - 确认收货 → 转到"已完成"
  - ✅ `refund()` - 拒收退款 → 转到"已取消"
- **不可执行操作**：
  - ❌ `pay()` - 已经支付
  - ❌ `ship()` - 已经发货
  - ❌ `cancel()` - 配送中，只能拒收
  - ❌ `review()` - 还未完成

### 4. 已完成（Completed）
- **可执行操作**：
  - ✅ `review()` - 评价订单
- **不可执行操作**：
  - ❌ `pay()` - 已完成
  - ❌ `ship()` - 已完成
  - ❌ `deliver()` - 已完成
  - ❌ `cancel()` - 已完成
  - ❌ `refund()` - 已完成（如需退货请联系客服）

### 5. 已取消（Cancelled）
- **终态**：所有操作都不可用
- **不可执行操作**：
  - ❌ 所有操作

## 典型流程

### 流程1：正常购物
```
待支付 --pay()--> 已支付 --ship()--> 配送中 --deliver()--> 已完成 --review()--> 结束
```

### 流程2：未支付取消
```
待支付 --cancel()--> 已取消
```

### 流程3：支付后退款
```
待支付 --pay()--> 已支付 --refund()--> 已取消
```

### 流程4：配送中拒收
```
待支付 --pay()--> 已支付 --ship()--> 配送中 --refund()--> 已取消
```

## 状态特征

| 状态 | 类型 | 可转换到 | 说明 |
|------|------|---------|------|
| 待支付 | 初始状态 | 已支付、已取消 | 订单创建后的初始状态 |
| 已支付 | 中间状态 | 配送中、已取消 | 等待发货 |
| 配送中 | 中间状态 | 已完成、已取消 | 物流运输中 |
| 已完成 | 终态 | 无 | 正常完成的订单 |
| 已取消 | 终态 | 无 | 取消或退款的订单 |

## 扩展可能性

### 可以添加的状态：
1. **部分退款**：退部分商品
2. **售后中**：退货退款流程
3. **待评价**：已完成但未评价
4. **已评价**：评价后的终态
5. **异常状态**：物流异常、支付异常等

### 可以添加的操作：
1. **modify()**：修改订单
2. **pay_again()**：重新支付（超时后）
3. **track()**：查询物流
4. **apply_after_sale()**：申请售后
5. **extend_time()**：延长收货时间

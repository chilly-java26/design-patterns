桥接模式就是：
1. 一个维度（格式化）通过继承来扩展
2. 另一个维度（存储）通过接口来扩展
3. 用一个引用（桥梁）把它们连接起来，让两个维度可以自由组合、独立变化。

桥接模式的选择标准：
1. 确定主要概念：日志收集器（LogCollector）
2. 确定两个变化维度：格式化（继承）、存储（组合）
3. 选择规则：
- 更"本质"的特征 → 用继承（格式化是LogCollector的本质特征）
- 更"外部"的依赖 → 用组合（存储是外部依赖）
